# 排版与配色规范（精简版）

> 本文件仅保留 AI 生成 PPT 时 **必须独立于主数据文件（SKILL.md / lesson_structure.json / image_prompts.json）之外** 的视觉规范。学科色值、学科特色元素、场景结构等数据请直接查询主数据文件，不在本文件重复。

---

## 一、全局排版规范

### 1.1 页面结构与间距（强制标准）

| 项目 | 规范 |
|:---|:---|
| 页宽 | 16:9 宽屏（1280×720px） |
| 页边距 | 上下 40px，左右 48px |
| 内容区 | 页眉 80px → 内容区 560px → 页脚 80px |
| 网格 | 12 列网格，列间距 8px |
| 对齐 | 左对齐为主，标题可居中 |
| 标题-正文间距 | 16pt |
| 段落间距 | 12pt |
| 正文行高 | 1.5 倍 |

### 1.2 通用字体规范

| 类型 | 中文 | 英文 | 字号 | 字重 |
|:---|:---|:---|:---|:---|
| 主标题 | 思源黑体 Bold / 微软雅黑 Bold | Calibri Bold / Arial Bold | 36pt | Bold |
| 页面标题 | 思源黑体 Bold / 微软雅黑 Bold | Calibri Bold / Arial Bold | 32pt | Bold |
| 二级标题 | 思源黑体 Medium | Calibri Medium | 28pt | Medium |
| 正文 | 思源黑体 / 微软雅黑 | Calibri / Arial | 24pt | Regular |
| 小字/注释 | 思源黑体 Light | Calibri Light | 18pt | Light |
| 公式 | — | Cambria Math | 随正文 | — |
| 古诗文 | 楷体 / 思源宋体 | — | 同正文 | Regular |

### 1.3 装饰原则

- **几何优先**：仅使用线条、色块、圆点等几何元素
- **留白呼吸**：每页文字占比 ≤ 60%
- **视觉层次**：通过字号、字重、颜色三级层次引导视线
- **一致性**：相同功能的元素使用相同样式

## 二、三学段视觉差异化规范

> 学段差异化的 **配色饱和度、字号、装饰元素** 必须遵循以下规范。具体学科主题色查询 `SKILL.md` §支持学科表格。

### 2.1 小学学段

| 项目 | 规范 |
|:---|:---|
| 标题字号 | 40-44pt |
| 正文字号 | 30-34pt |
| 配色等级 | 高饱和度主题色 + 明黄 `#FFD54F` / 天蓝 `#4FC3F7` 辅助 |
| 装饰元素 | 圆角图形、简化卡通图标、星星/花朵奖励元素 |
| 版式 | 单页信息密度低，图文比 1:1，大量留白 |
| 风格关键词 | 趣味活泼、鼓励式、互动感强 |

### 2.2 初中学段

| 项目 | 规范 |
|:---|:---|
| 标题字号 | 36-40pt |
| 正文字号 | 26-30pt |
| 配色等级 | 中饱和度主题色 + 浅灰 `#E0E0E0` / 浅蓝辅助 |
| 装饰元素 | 几何线条装饰、简易图标、色块分区 |
| 版式 | 图文并茂，图文比 2:1，层次清晰 |
| 风格关键词 | 过渡衔接、思维进阶、方法引领 |

### 2.3 高中学段

| 项目 | 规范 |
|:---|:---|
| 标题字号 | 32-36pt |
| 正文字号 | 24-28pt |
| 配色等级 | 低饱和度主题色 + 灰白 `#F8F9FA` / 浅灰辅助 |
| 装饰元素 | 细线分割、几何色块、极简图标 |
| 版式 | 信息密度适中，图文比 3:1，注重逻辑层次 |
| 风格关键词 | 学术严谨、逻辑严密、深度探究 |

### 2.4 跨学科配色规则

| 项目 | 规范 |
|:---|:---|
| 主色调 | 选择涉及学科中最具代表性的主题色 |
| 辅助色 | 选取 2-3 个涉及学科的主题色，按比例渐变 |
| 连接线 | 使用灰色虚线 `---` 或渐变色连接不同学科元素 |
| 标记系统 | 每个学科分配一个专属小图标作为视觉锚点 |

## 三、学科专属视觉规范（精要版）

> 以下为 **各学科排版/图示的必要格式规范**，学科特色元素（如"文言文断句框"、"公式推导框"等）的具体清单请查询 `lesson_structure.json` → `elements` 字段。

### 3.1 语文

| 元素 | 规范 |
|:---|:---|
| 文言文排版 | 竖排优先，句读标点全角 |
| 诗词展示 | 居中排版，每句独立成行，注解放右侧 |
| 修辞手法 | 主题色高亮 + 修辞名称标注框 |
| 范文批注 | 页边批注区，主题色区分师评与生评 |
| 古诗文字体 | 楷体 / 思源宋体 |

### 3.2 数学

| 元素 | 规范 |
|:---|:---|
| 公式排版 | Cambria Math 字体，居中或行内，编号右对齐 |
| 推导过程 | 分步箭头 `→` 连接，每步独立一行，结论用 `∴` 引出 |
| 坐标系 | 标准 x-y 轴，箭头标注，刻度等距 |
| 几何图形 | 矢量绘制，辅助线虚线 |

### 3.3 英语

| 元素 | 规范 |
|:---|:---|
| 四线三格 | 标准四线三格区域 |
| 对话气泡 | 圆角矩形气泡，指向说话人 |
| 时态时间线 | 横向时间轴，标注各时态 |
| 音标标注 | 国际音标紧跟单词后方，浅色显示 |

### 3.4 物理

| 元素 | 规范 |
|:---|:---|
| 受力分析图 | 矢量箭头标注，方向正确，大小成比例 |
| 电路图 | 标准 GB/T 4728 电路符号，直线连接 |
| 波形图 | 标准正弦/余弦曲线，标注振幅/周期 |
| 实验装置图 | 工程制图风格，标注仪器名称 |

### 3.5 化学

| 元素 | 规范 |
|:---|:---|
| 电子式 | 标准电子式书写，孤对电子用 `..` 表示 |
| 结构式 | 结构简式或键线式，Cambria Math 字体 |
| 化学方程式 | 反应物→生成物，条件标注在等号上方 |
| 实验装置 | 标准实验装置示意，标注器材 |

### 3.6 生物

| 元素 | 规范 |
|:---|:---|
| 细胞结构图 | 标准生物插图风格，标注细胞器 |
| 食物链/食物网 | 箭头方向正确，层级清晰 |
| 遗传谱系图 | 标准系谱符号（□○■●） |
| 代谢流程图 | 箭头+反应步骤，场所标注 |

### 3.7 历史

| 元素 | 规范 |
|:---|:---|
| 年代标尺 | 横向或纵向时间轴，关键节点标注 |
| 史料原文 | 竖排可选，米色底色 |
| 历史地图 | 复古色调，疆域边界清晰 |
| 比较分析 | 表格形式，多维对比 |

### 3.8 地理

| 元素 | 规范 |
|:---|:---|
| 地图标注 | 分层设色，等高线/等温线清晰 |
| 气候图表 | 气温曲线 + 降水柱状图组合 |
| 地形剖面 | 标准剖面图，标注海拔 |
| 统计图表 | 柱状图/折线图/饼图三选一 |

### 3.9 政治

| 元素 | 规范 |
|:---|:---|
| 政策条文 | 引用框展示，标注出处 |
| 概念关系 | 同心圆/树状/辐射状结构 |
| 案例分析 | 案例卡片 + 分析框架 |
| 逻辑流程 | 判断→推理→结论箭头链 |

## 四、通用色彩系统

### 4.1 功能色彩（全学科通用）

| 用途 | 色值 | 说明 |
|:---|:---|:---|
| 页面底色 | `#FFFFFF` 纯白 | 保证投影亮度 |
| 卡片底色 | `#F8F9FA` 浅灰 | 内容卡片区分 |
| 主文字 | `#212121` 深灰 | 保证阅读对比度 |
| 次文字 | `#757575` 中灰 | 注释、辅助文字 |
| 链接/强调 | `#1976D2` 蓝色 | 超链接、重要标注 |
| 成功/正确 | `#4CAF50` 绿色 | 肯定、通过 |
| 警告/注意 | `#FF9800` 橙色 | 提醒、注意事项 |
| 错误/危险 | `#F44336` 红色 | 错误、禁止操作 |

### 4.2 配色使用规则

| 规则 | 说明 |
|:---|:---|
| 主题色占比 | 学科主题色在页面中约占 15%，其余 85% 为白底/中性色 |
| 主色调使用 | 封面标题、页眉、关键色块使用学科主题色 |
| 辅助色使用 | 卡片背景、二级按钮、图表填充使用辅助色 |
| 高亮标注 | 重点内容用学科主题色加粗或色块标注 |
| 图表配色 | 数据系列在学科主题色附近取色 |
| 打印友好 | 所有颜色支持黑白打印（灰度转换后可区分层次） |

## 五、生成检查清单

> AI 在输出 PPT 模板前必须逐项确认。学科色值、特色元素、场景结构的详细数据请查询对应主数据文件。

- [ ] **学段视觉匹配**：字号、配色饱和度、装饰元素符合目标学段规范
- [ ] **学科识别**：主题色、特色元素已正确选定（查询 `SKILL.md` + `lesson_structure.json`）
- [ ] **场景识别**：页面结构匹配教学场景（查询 `lesson_structure.json` → `scenarios`）
- [ ] **排版规范**：页边距、间距、行高、网格符合标准
- [ ] **字体规范**：中英文混排、公式字体、古诗文字体符合规范
- [ ] **内容槽位**：每页 `slots` 已定义（查询 `lesson_structure.json` → `elements`）
- [ ] **装饰说明**：每页 `decorations` 已列出
- [ ] **图片提示**：封面/内页配图使用对应提示词（查询 `image_prompts.json`）
- [ ] **风格一致**：全局风格统一，无突兀元素
- [ ] **打印友好**：配色支持黑白打印
