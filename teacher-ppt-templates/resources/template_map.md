# AI 生成工作流映射核心

> 本文件是 AI 生成 PPT 模板时的**核心路由地图**，仅保留必须独立于其他主数据文件之外的功能框架数据。
> AI 工作流：用户请求 → Step1 读取 SKILL.md → Step2 查询本文件 → Step3 读取对应模板结构 → Step4 生成输出

---

## 一、核心概念与快速映射表

### 1.1 三维决策轴

**学段 (Stage)** → 决定风格与页数，数据来源：`lesson_structure.json` → `stages`

| 学段 | 页数范围 | 风格 | 字号(标题/正文) | 配色调级 |
|:---|:---|:---|:---|:---|
| 小学 | 6-8页 | 趣味活泼风 | 40-44pt / 30-34pt | 高饱和度 |
| 初中 | 8-10页 | 过渡衔接风 | 36-40pt / 26-30pt | 中饱和度 |
| 高中 | 10-12页 | 学术严谨风 | 32-36pt / 24-28pt | 低饱和度 |

**学科 (Subject)** → 决定主题色与特色元素，数据来源：`SKILL.md` → 支持学科表格

**场景 (Scenario)** → 决定页面结构与核心环节，数据来源：`lesson_structure.json` → `scenarios`

### 1.2 模板类型决策树

```
学科 × 学段 × 场景 → 模板 Key 决策：

  场景类型判断：
  ┌─ 是【实验课】（物理/化学/生物）→ science_lab
  │
  ├─ 是【大单元/PBL/STEAM】 → extended_10page
  │
  └─ 其他常规场景 → standard_8page

  页面调整逻辑：
  ┌─ 小学学段 → 基础模板上减少2-4页，保留核心环节
  ├─ 初中学段 → 使用基础模板完整结构
  └─ 高中学段 → 在基础模板上增加2-4页深度探究环节
```

### 1.3 快速模式自动路由

| 触发关键词 | 自动配置 | 附加输出 |
|:---|:---|:---|
| 新教师、公开课、快速备课 | 默认：核心素养模板；默认学段：初中 | 教学设计文档 + 备课 Checklist |
| 备课组、学期备课、批量生成 | 默认：大单元模板 | 单元规划文档 + 教学进度甘特图 |
| 说课、教学比赛、说课PPT | 默认：说课模板 | 配套说课稿 + 评委关注点 + 答辩问答库 |

| 模板 Key | 名称 | 适用场景 | 页数 |

## 四、AI 执行工作流

### 4.1 请求解析流程

```
用户请求进入 →
  ├─ 解析【学段】关键词 → 小学/初中/高中
  ├─ 解析【学科】关键词 → 9大学科/跨学科组合
  ├─ 解析【场景】关键词 → 10大场景/快速模式触发词
  │
  ├─ 查询【快速模式】→ 若命中触发词则执行自动配置
  │
  ├─ 根据学段×学科×场景 → 查询【模板类型决策树】→ 获得模板Key
  │
  ├─ 读取【模板类型定义】→ 获取核心页面序列
  │
  ├─ 读取【学科特色元素索引】→ 获取特色元素清单
  │
  └─ 按【风格规范】+【图片提示词】→ 生成完整PPT方案
```

### 4.2 输出内容清单

AI 生成 PPT 模板时必须包含：

1. **确认信息**：学段 + 学科 + 场景 + 概述方案
2. **配色与风格说明**：主题色 + 辅助色 + 字体规范 + 整体风格
3. **PPT 页面结构表**：每页页码 + 标题 + 核心内容指引 + 学科特色元素 + 学段差异化元素
4. **使用提示**：占位内容替换建议 + 元素使用建议
5. **可选附加输出**：配套教学设计文档 / 快速模式辅助材料

### 4.3 跨学科场景特殊处理

| 处理项 | 规则 |
|:---|:---|
| 主色调 | 选择涉及学科中最具代表性的主题色 |
| 辅助色 | 选取2-3个涉及学科的主题色，按比例渐变 |
| 连接线 | 使用灰色虚线连接不同学科元素 |
| 标记系统 | 每个学科分配专属小图标作为视觉锚点 |
| 驱动问题 | 每页固定位置展示核心驱动问题 |
| 反思迁移 | 预留留白区引导跨学科思维迁移 |

## 六、生成检查清单

> AI 输出 PPT 模板前必须逐项确认

- [ ] **学段匹配**：字号、配色饱和度、装饰元素符合目标学段规范
- [ ] **学科识别**：主题色、特色元素已正确选定
- [ ] **场景适配**：页面结构匹配教学场景核心环节
- [ ] **排版规范**：页边距、间距、行高、字体符合标准
- [ ] **内容完整**：每页内容指引清晰，特色元素已预留
- [ ] **图片提示**：封面/内页配图使用对应学科场景提示词
- [ ] **跨学科兼容**：若为跨学科场景，配色与标记系统已配置
- [ ] **风格一致**：全局风格统一，符合打印友好要求
