# 设计令牌（Design Tokens）说明

本文件定义"材质 → 视觉"的映射规则。渲染时先读 `assets/style-tokens.json`（数据），再遵循本文件的合成与回退规则。

## 令牌 Schema

每种风格最终转化为以下 CSS 自定义属性，注入简历模板的 `:root`：

| 令牌 | 含义 | 示例 |
|------|------|------|
| `--bg` | 页面背景色 | `#0a0e14` |
| `--surface` | 卡片 / 区块底色 | `#111722` |
| `--accent` | 点缀 / 强调色 | `#00e5ff` |
| `--text` | 正文文字色 | `#d7f7ff` |
| `--muted` | 次要文字色 | `#6fa8bf` |
| `--border` | 边框色（建议含透明度） | `rgba(0,229,255,.35)` |
| `--shadow` | 区块光影 | `0 0 24px rgba(0,229,255,.25)` |
| `--texture` | 背景纹理（CSS 背景值，可为渐变 / 图案） | `linear-gradient(...)` |
| `--font-display` | 标题字体气质（字体栈） | `"Playfair Display", serif` |
| `--font-body` | 正文字体气质（字体栈） | `"Inter", sans-serif` |

> 字体默认使用系统字体栈（含中文回退，如 `"PingFang SC"`、`"Microsoft YaHei"`、`"Songti SC"`），保证离线可用；若运行环境可联网，可在模板 `<head>` 加载对应 Google Fonts 以增强气质。

## 分组默认令牌

JSON 的 `groups` 段为 13 个分组各提供一套默认令牌，是绝大多数材质的渲染基线。摘要如下（完整值见 JSON）：

- **metal**：暗枪灰底 + 金属金 / 银点缀 + 拉丝光泽，衬线展示字。
- **glass**：浅色 + 半透明表面 + 冷蓝点缀 + 磨砂高光。
- **plastic**：浅底 + 活泼强调色 + 圆润无衬线。
- **gem**：深底 + 紫 / 虹彩点缀 + 宝石光晕 + 衬线展示字。
- **geology**：暖褐底 + 大地色点缀 + 岩理条纹。
- **nature**：浅绿底 + 叶绿点缀 + 自然留白。
- **food**：暖橙浅底 + 食欲暖色 + 友好无衬线。
- **fabric**：米色底 + 暖线点缀 + 织物细纹 + 优雅衬线。
- **tech**：近黑底 + 青色霓虹 + 网格纹理 + 科技无衬线。
- **liquid**：深蓝底 + 水青点缀 + 流体光晕。
- **paint**：米白底 + 艺术红 / 多色斑块 + 艺术衬线。
- **ceramic**：陶土米色 + 赤陶点缀 + 温润高光。
- **other**：中性灰底 + 安全回退样式。

## 显式材质覆盖

JSON 的 `materials` 段为部分代表材质提供**覆盖值**（优先级高于分组默认），例如：

- `青铜`：暗青褐金属 + 铜绿点缀 + 做旧拉丝 + 衬线展示字。
- `毛玻璃`：浅冷底 + 强磨砂模糊 + 半透表面 + 冷蓝点缀。
- `霓虹`：近黑底 + 品红 / 青双霓虹 + 发光阴影。
- `大理石`：浅底 + 灰白脉络纹理 + 金线点缀。
- `水彩质感`：米白底 + 多色水彩晕染斑块。
- `丝绸`：浅底 + 丝光渐变 + 柔粉点缀。
- `钻石`：深底 + 冰蓝折射光斑 + 高反光。
- `巧克力`：暖棕底 + 可可色点缀。
- `极光`：深底 + 绿紫极光渐变光晕。
- `火山岩`：近黑底 + 熔岩橙红点缀 + 多孔岩理。

（完整覆盖集见 `assets/style-tokens.json` 的 `materials`。）

## 语义合成规则（对任意材质）

当某材质既无显式覆盖、也需进一步细化时，按以下启发式从**材质语义**推导令牌：

1. **识别材质类别词**：金属 / 玻璃 / 水晶 / 木 / 石 / 水 / 光 / 食物 / 布 / 纸 / 陶 … 决定基础分组与底色冷暖。
2. **识别质感修饰词**：
   - "磨砂 / 哑光 / 毛" → 降低光泽、加柔和高光、模糊边框。
   - "镜面 / 拉丝 / 镀铬 / 抛光" → 加金属高光渐变、锐利边框。
   - "冰 / 裂 / 透 / 琉璃" → 冷色、半透明、折射光斑。
   - "带锈迹 / 老 / 旧 / 虫蛀 / 腐" → 降饱和、加斑驳纹理、暖褐叠加。
   - "荧光 / 霓虹 / 极光 / 全息" → 提高亮度、加发光阴影（`box-shadow`/`text-shadow` glow）、深底。
   - "糖霜 / 裱花 / 奶油 / 蛋白" → 浅暖底、柔白高光、圆润字。
3. **识别颜色线索词**：青、翠、墨、琥珀、赤、银、金、黑、雪、珊瑚 … 映射到 `--accent` 与 `--texture` 色相。
4. **组合**：以上推导在分组默认令牌基础上覆盖对应字段，未涉及的字段保留分组默认。

## 多材质组合

- 以**第一个材质**为主：`--bg`、`--accent`、`--text` 取主材质。
- 其余材质作为**纹理 / 点缀叠加**：将其 `--texture` 以 `,` 拼接进主材质的 `--texture`，或将其 `--accent` 用作次级强调（如标题下划线、分隔线）。
- 避免冲突：若两个材质底色一深一浅，以主材质为准，次材质只贡献纹理，不覆盖底色。

## 回退策略

- 材质不在 `style-catalog.md` → 提示用户从库中选择近似材质，或按字面语义尝试合成。
- 合成后仍缺字段 → 继承分组默认；分组默认仍缺 → 使用 `neutral_fallback`（中性现代风：浅灰底、深字、蓝色点缀、无衬线）。
- 始终保证输出**有完整配色与排版**，绝不退化为无样式页面。
