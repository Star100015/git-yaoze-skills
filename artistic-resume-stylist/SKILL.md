# 艺术风格简历生成助手 (Artistic Resume Stylist)

将普通简历重排为各种"材质 / 艺术风格"版本，并以 HTML 格式交付。

## 一、能力边界（每次触发都先阅读）

- 本技能**只负责重排版式与视觉风格**，不编造、不夸大、不删改用户的简历经历与事实内容；用户提供什么内容就呈现什么内容。
- 无法保证对每一种 exotic 材质做到"物理级精确还原"，只能尽量还原其**配色、质感、光影、纹理气质**。
- 产物为**预览 / 投递草稿**，非官方公证或防伪文件。
- 必须先有用户的**原始简历内容**（纯文本 / Markdown / 结构化信息）；未提供时应先向用户索取。
- 内置风格数量庞大（约 180+ 种材质），个别冷门材质的视觉可能需要用户二次微调，属正常。

## 二、新手引导：从内置全部艺术风格中任选

技能内置一份完整"材质风格库"，覆盖以下 13 大类（每一类下含多个具体材质）。你可以：

- 指定**单一材质**（如"青铜风格"）；
- 指定**组合材质**（如"毛玻璃 + 霓虹"混合气质）；
- 不确定时，直接说"给我看看有哪些风格"，技能会列出完整菜单供你挑选。

**完整风格菜单（所有内置材质名称）见 `references/style-catalog.md`。** 大类速览：

- **金属**：青铜、黄铜、镜面金属、拉丝金属、哑光金属、生锈铁皮、紫铜、钛金属、镀铬金属、航空铝、青铜鎏金、铸铁…（共 22 种）
- **玻璃 / 透明**：毛玻璃、透明亚克力、琉璃、彩色玻璃、冰裂纹玻璃、钢化玻璃、磨砂玻璃灯罩、玻璃马赛克、全息投影膜…（共 19 种）
- **塑料 / 合成**：磨砂塑料、彩色 PVC、哑光 ABS、珠光塑料、荧光塑料、碳纤维塑料复合、仿木纹塑料、磨砂塑料瓶…（共 12 种）
- **宝石 / 晶体**：钻石、水晶球、珍珠母贝、冰晶、琥珀、树脂、孔雀石（共 7 种）
- **地质 / 石材 / 土壤**：沙土、大理石、花岗岩、火山岩、水泥、砂岩、各类森林土壤与草地…（共 21 种）
- **自然 / 植物 / 木质**：青苔、苔藓、胡桃木、藤编、竹编、椰壳、树皮、落叶、积雪、各类草地…（共 27 种）
- **食物 / 饮品**：雪糕、太妃糖、爆米花、巧克力、面包、蜂蜜、牛奶、红酒、橙汁、咖啡加奶泡、啤酒…（共 13 种）
- **织物**：蚕丝、绒布、丝绸、绸缎、牛仔布、羊毛、天鹅绒、灯芯绒、麻布、羊绒、帆布、锦缎、蕾丝…（共 19 种）
- **电子 / 科技 / 光效**：霓虹、荧光、电路板、全息投影、液态金属、赛博朋克霓虹管、柔性 OLED 屏、极光、3D 打印树脂…（共 15 种）

## 三、触发方式

当用户的表述命中以下任一模式时，启用本技能：

- 提及"简历"且出现任一内置材质名（见 `references/style-catalog.md`），如"把我的简历做成青铜风格""来一份毛玻璃材质的简历"。
- 直接要求"艺术风格简历""简历艺术化""给简历换个艺术风格"。
- 提到"材质 / 纹理 / 质感"+"简历"，如"用赛博朋克霓虹管质感做简历"。

命中后，先按第二节确认风格（若未指定则展示菜单），再进入工作流程。

## 四、工作流程

1. **收集原始简历**：若用户未提供，先索取（接受文本 / Markdown / 结构化信息）。
2. **确认目标风格**：从 `references/style-catalog.md` 选取 1 种或组合多种材质；不在库中的材质提示用户从库中选择或按"近似材质"处理。
3. **获取设计令牌**：
   - 读取 `references/style-tokens.md` 与 `assets/style-tokens.json`。
   - 优先取该材质的显式令牌（JSON 的 `materials` 段）；否则取其所属分组的默认令牌（`groups` 段）；再按"语义合成规则"细化（如"青铜"→暗青褐金属、做旧拉丝、衬线展示字）。
   - 组合多种材质时，以第一种为主色调，其余作为纹理 / 点缀叠加。
   - 全部未命中时回退到 `neutral_fallback`（中性现代风）。
4. **选择布局骨架**：从 `assets/` 选用 `resume-template-minimal.html`（极简单栏）或 `resume-template-magazine.html`（现代双栏 / 杂志式），将令牌写入 CSS 变量（`--bg`、`--surface`、`--accent`、`--text`、`--muted`、`--border`、`--shadow`、`--texture`、`--font-display`、`--font-body`）。
5. **填充内容**：将用户简历内容套入骨架的语义区块（头部 / 简介 / 经历 / 技能 / 教育 / 作品）。
6. **HTML 交付**：产出单文件（内联 CSS，无外部依赖），可直接浏览器预览。

## 五、参考资料

- `references/style-catalog.md`：完整材质清单与分组（触发校验 + 新手菜单）。
- `references/style-tokens.md`：令牌 schema、分组默认令牌、语义合成与回退规则。
- `assets/style-tokens.json`：令牌数据（分组默认 + 典型材质显式映射 + 中性回退）。
- `assets/resume-template-minimal.html`、`assets/resume-template-magazine.html`：布局骨架。
